# 🧠 AI Lie Detector

## 💡 Overview
The **AI Lie Detector** is an offline Python application that analyzes written statements and predicts whether they are more likely to be **Truthful** or **Deceptive**.

It uses **Natural Language Processing (NLP)** and **Machine Learning** to study linguistic patterns commonly associated with lies — similar to tools used in **forensic linguistics and psychology research**.

---

## 🚀 Features

### 🗣 Statement Analysis
- Analyzes any text statement
- Predicts:
  - **TRUTH ✅**
  - **LIE 🚨**

### 🧠 Machine Learning Model
- Uses **TF-IDF vectorization**
- Uses a **Naive Bayes classifier**

### 📊 Pattern Recognition
- Learns from example statements
- Identifies deceptive language patterns

### 🌐 Fully Offline
- No APIs
- No internet required
- Works entirely on local data
